## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/Tharunteja9948/Portfolio.git

# Navigate to project folder
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
